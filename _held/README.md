# Held pages (not published)

Jekyll does not publish folders whose names start with `_`, so nothing in here is served on aryehleibtoren.com.

These essay pages were taken off the live site before launch because each one marks itself as unreleased: a "HOLD publish" status line, an "Internal draft" banner, a "Sources (VERIFY before publication)" list, or inline `[VERIFY …]` notes.

To republish one: clean the page, `git mv` it back to `writing/`, and add it to `writing/index.html` or `writing/archive.html`.
